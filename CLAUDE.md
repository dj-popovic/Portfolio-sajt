# Project rules

Single-page portfolio for a two-person creative studio. Read `AGENTS.md` too: this is Next.js 16.4 — check `node_modules/next/dist/docs/` before using an API from memory (e.g. `proxy.ts` instead of `middleware.ts`, `next/root-params`, Cache Components are on).

## Non-negotiables

- **"Ember" is the colour palette's codename, never the studio name.** Don't hardcode it as a name anywhere.
- **Keep placeholders** until the owners decide. Name placeholders — `<logo>`, `[studio]`, `<Name One>`, `<Name Two>`, `[Novi Sad]` — are never translated (`src/lib/placeholders.ts` / the message files). The Work concepts are named and filled in (the owners asked for no brackets there): Copper & Oak, Northbound, Stillwater, Tako, never translated either. Bracketed draft copy (`[founder photo 1]`, `[a clear brief & timeline]`, `[From €X …]`) is translated but keeps its brackets, so it still reads as a placeholder in every language.
- **The Claude Design export is the visual source of truth.** Skills and reviews are for polish, never to redesign. Section styles in `src/styles/sections.css` are ported from it; changes are marked `build:`.
- Open items (photos, name, prices, backend, legal) are tracked in `docs/OPEN-ITEMS.md` — keep it current.

## Design system (from the brief + export)

- Palette (Tailwind theme in `src/app/globals.css`): base `#0E0B0A`, surface `#1A1513`, cream text `#F5EDE4`, ember `#FF6B35`, amber `#FFB627`, paper `#FBF6F0`, coal (footer) `#080605`, ink `#2A211C` for text on light sections.
- Light sections: About, Work, Find your fit. Everything else dark; footer darkest.
- **Liquid glass is the house material** (the owners' call, from the hero on): dark translucent panes with a lit rim, blur + saturation and warm ember light behind them to bend (`.glass` pills in the header, the glass panes in What we offer). New section work follows it, still within the export's layout and copy.
- Type: **Unbounded** only for large display (hero, section titles, big numbers); **Inter** for body/UI; **JetBrains Mono** for small numerals ("01", "Step 01 / 04").
- Section order: Hero → About → What we offer → Work → How we work → Find your fit → Contact → Footer.

## Stack conventions

- Next.js App Router, TypeScript, Tailwind 4, next-intl (EN at `/`, `/sr` Serbian **Latin**, `/ru`, `/de`). Strings live in `messages/*.json`; rich tags `<glow>`, `<b>`, `<br></br>`; quote angle-bracket placeholders as `'<logo>'`.
- Use typographic apostrophes (’) in messages — a straight `'` can start ICU quoting. Titles keep a no-break space before " — " so a line never starts with a dash. After editing messages run `npm run check:messages` (keys, ICU arguments/tags, placeholders, parsing).
- Go easy on em dashes in copy (a stacked-up "—" reads as AI cadence): use periods, commas or colons. They stay only in Russian where grammar needs them ("Мы — студия"). The concept demos have none either; a concept is named as its brand plus what it is (`work.items.*.what`), never "Tako — …".
- **GSAP (+ScrollTrigger/SplitText) is the main animation engine**, all scroll-driven motion. **Motion (`motion/react`) only for small UI interactions.** Lenis for smooth scroll. React Three Fiber for 3D (the hero orb).
- React Bits: pull only components we use (TS + Tailwind variant, from GitHub raw — reactbits.dev is blocked here) and adapt to Ember.
- Demo mini-sites (Work section) are fictional client brands: their inner content stays in English; only our frame around them is translated.
- Respect `prefers-reduced-motion` everywhere (no pins/scrubs, simple fades). The global rule in `globals.css` kills loops and movement but keeps 0.15s opacity/colour transitions; `MotionPreferences` puts Motion in `reducedMotion="user"`. GSAP code branches with `gsap.matchMedia`.
- Reveals hide with **opacity, not visibility**: the pre-reveal rule in `motion.css` is `opacity: 0`, and tweens of anything focusable or meaningful animate `opacity` (not `autoAlpha`), so content that hasn't scrolled in yet stays in the tab order and the accessibility tree. `autoAlpha` is fine for decorative, `aria-hidden` layers. Pinned sequences that hold focusable things scroll them into place on `focusin` (About cards, the services index).
- Scroll lock (`useScroll().lock()`, for overlays and the menu) keeps the scrollbar: hiding it (`overflow: hidden`) widens the page and everything behind jumps sideways. It holds wheel, touch and scroll keys instead; an overlay's own scroller is marked `data-lenis-prevent` with `overscroll-behavior: contain`. A `scrollTo` asked for during a lock (a link in the phone menu) runs when the lock is released: a stopped Lenis would drop it. `force: true` moves the page anyway (the demo window lining up the card it closes into).
- Fonts: `subsets` in `src/lib/fonts.ts` only controls **preloading** (every subset is in the CSS and loads on demand), so keep it at `["latin"]`.

## Workflow

- Commits: author `dj-popovic <dj.popovic5503@gmail.com>` (set in local git config), Claude as co-author via trailer. Push straight to `main`.
- Visual check: `npm run build && npx next start -p 3100`, then `node scripts/shoot.mjs http://localhost:3100 .shots /` for section screenshots at 1440/390, or `node scripts/scrollshots.mjs http://localhost:3100/ .shots/scroll 260` to step through the scroll choreography with real wheel events (Lenis-aware).
- Motion map: `src/components/motion/` (Lenis provider, reveal orchestrator, heading sweep, panel clips), `AboutStage.tsx` (pinned signature sequence), `src/components/services/` (What we offer: `ServicesDeck` pins the section on big screens and stacks the glass panes as you scroll, each sliding up over the last while a light behind shifts and the index follows; phones get sticky stacking panes, reduced motion the plain grid; `ServiceGlyph` draws each service's symbol in ember dots via `--draw`, hidden by default in CSS: a ScrollTrigger refresh can wipe a `gsap.set` pre-state and a rewind then falls back to the CSS, so resting states belong in CSS, not in a set), `src/components/three/` (the hero orb: a fixed R3F layer drawn in screen pixels; on scroll it unravels into a thread of dots that lands on the About ★ tile), `src/components/reactbits/` (adapted React Bits — keep their LICENSE.md).
- About: `AboutStage.tsx` writes the opening panel's rectangle into `orb.panel`, so the orb layer can glow along its edge and burst the absorbed dots out as sparks; `.about-heat` makes the panel open hot and cool to paper. The founders are 3D cards in `src/components/about/` (`FounderCard`, `IconSphere`, and `FounderDialog`, which grows a full-screen clip out of the card, turning upright from the card's tilt, and folds back the same way: content out, sheet onto the card, card swapped in under it, sheet dissolves); stacks and contacts live in `src/lib/founders.ts`, logos and brand colours in `src/lib/tech-icons.ts` (generated from Simple Icons, CC0; black brand colours are lifted so they show on the dark profile).
- CSS gotcha: never put `translate` and `transform` in one rule — the CSS minifier drops the `translate`. Combine them into a single `transform`.
- Hero orb: shared state, layout and lattice in `src/lib/orb.ts`; `OrbControls.tsx` is the invisible hit area in the hero (drag, hover, tap ripple, arrow keys/Enter) and writes `--orb-x/y/r` for the aura and hint; `canvas/Orb2D.tsx` draws it inside the hero for reduced motion (still, turns by hand) and no-WebGL. `isStacked()` and the stacked-hero media query in `sections.css` must stay in sync.
- Header: dark liquid-glass pills (`.glass` in `sections.css`), fixed from the first screen, with a section marker (Motion `layoutId`) and the language dropdown `layout/LangMenu.tsx` (native names, no flags). Language links use `prefetch={false}`: opening the menu would fetch and parse three whole pages mid-animation. The phone menu sheet counts as an overlay (`overlay.push`), so the orb rests under it. The header's Start a project button keeps a soft ember glow on purpose.
- Work: `work/concepts.ts` (the four concepts), `work/marks.tsx` (`ConceptMark`, icon-only brand marks for each concept: used in the cards, previews, demos and the window). Cards (`ConceptCard`) are panes of the founder cards' dark material on the paper: they tip up into place on scroll (`WorkGallery`), tilt and catch a glare under the pointer, an Open pill trails the cursor and a warm light follows the pointer across the section. Previews (`work/previews.tsx`, `src/styles/previews.css`) are faithful replicas drawn at the demo's own size and zoomed to the card (`--k` for the 960px sites, `--pk` for the 300×640 phones): the sites scroll themselves down the page and back at an even pace while hovered (never tied to the pointer, which can be too quick; measured in layout px, so the card's tilt can't cut the page short), the phones keep their status bar and run through their screens (`data-screen`); touch screens play whatever is in view. Light sections enter with an arched top edge that flattens (`motion/PanelClip.tsx`, a `path()` clip), not a widening box.
- Work demos: `src/components/work/WorkWindow.tsx` opens a concept out of its card and closes onto the card of whichever concept is showing (scaled down to its preview, cropped to its shape, fading as it lands; if switching concepts left that card off screen, the page lines it up behind the scrim first; Esc is a `useEffectEvent`, so it always means the concept on show); its dark glass bar names the concept and switches between all four in place (portal, focus trap, page scroll locked, background renderers paused via `src/lib/overlay.ts`). Each concept is its own lazily loaded mini-site in `src/components/work/demos/<name>/`; the two app concepts share `demos/Phone.tsx` (device frame, wide/narrow layout, zoom-to-fit). Demo styles/keyframes: `src/styles/demos.css`. The Northbound charts follow the dataviz rules (validated categorical colours for the money flows, solid hairline grid, bars capped at 24px; the flow chart switches to a slim layout with a legend under 30rem, never a horizontal scroll).
- Never tween `clip-path` strings directly (browsers normalise them) — tween numbers and write the string (`motion/clip.ts`).
